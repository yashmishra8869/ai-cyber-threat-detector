PROJECT OVERVIEW

About the AI Threat Detector

Project objective

This project demonstrates how machine learning can be used to detect cybersecurity threats by classifying network traffic records as normal or malicious. It is built as a final-year B.Tech educational project and focuses on the analytical side of cyber threat detection.

The system uses a trained model on NSL-KDD data and provides a practical interface for record-level and batch prediction.

Technologies used

  • Python and Flask
  • scikit-learn Random Forest
  • Pandas, NumPy, joblib
  • Bootstrap 5 and Chart.js
  • SQLite for prediction history

Problem statement

Modern digital systems generate large volumes of network traffic. Identifying whether a record represents normal traffic or an attack is a central problem in cybersecurity analytics and threat detection.

Project objectives

  • Train a working binary classification model
  • Validate record structure against the NSL-KDD schema
  • Support single-record and batch analysis
  • Present results through a modern dashboard
  • Preserve a practical academic demo experience

Machine learning methodology

The system uses a complete scikit-learn pipeline with preprocessing for categorical features such as protocol type, service, and flag. Numeric features are scaled, and the final classifier is a Random Forest model trained with 80% training data and 20% testing data. The model is trained, evaluated, and saved for reuse in the Flask application.

Dataset information

The application is designed to work with the NSL-KDD dataset. The input features follow the standard 41-feature network traffic schema, with the additional `attack_name` and `difficulty` fields used for training and validation. The project does not introduce fake data or synthetic examples.

System scope and limitations

This is a feature-based classification project. It does not perform live packet inspection, does not monitor a real network, and is not an active intrusion prevention system. It is intended for educational demonstration and project presentation.
